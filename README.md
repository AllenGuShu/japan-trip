# 旅遊紀錄手冊

## 這次修正：手機上地點搜尋跳不出建議清單

### 問題原因
Google 官方提供的地點自動完成元件，會自己在頁面上「浮」出一個建議清單（業界叫它 pac-container），這個清單的位置是用螢幕座標即時計算的。但手機瀏覽器（尤其 iOS Safari）跳出鍵盤時，畫面可見範圍會被壓縮、變動，Google 這個元件對這種動態縮放的計算常常不準，導致建議清單雖然有抓到資料，卻顯示在看不到的地方（可能被鍵盤蓋住、或位置整個跑掉），這是這個 Google 元件在手機瀏覽器上滿常見的已知毛病，跟金鑰或設定都沒關係。

### 這次的解法
不再依賴 Google 那個會亂飄的浮動清單，改成**自己畫一個建議清單，直接嵌在輸入框正下方**，是表單裡真正的一般元素，不是浮動疊層，就不會再有跟鍵盤打架、定位跑掉的問題。

功能行為完全一樣：打字後跳出建議 → 點選 → 自動帶入正確地址與座標，只是改成更穩定可靠的實作方式。已經用模擬環境完整測試過整個流程（搜尋→顯示建議→點選→帶入資料→存檔）都正確。

## 部署步驟（GitHub Desktop + Vercel）

1. 用 GitHub Desktop 打開你的 repo
2. 把 app.js、style.css、sw.js 覆蓋貼進去
3. Commit to main → Push origin
4. Vercel 自動重新部署

## 測試方式

進任一趟旅遊 → 行程 → 單日編輯 → 新增行程點，在地點名稱欄位打幾個字，這次應該會直接在輸入框下方看到建議清單（不會再跑到看不到的地方），點選後會自動帶入地址。
