# 旅遊紀錄手冊

## 這次優化：動態畫面感

這輪沒有加新功能，純粹讓現有畫面「動起來」，感覺更有生命力、更像精品 App。

### 互動回饋
所有按鈕、標籤、分頁、浮動按鈕，按下去都會有輕微縮放的觸感回饋（像被按壓一樣），底部導覽切到當前分頁時圖示會有彈跳放大效果。

### 平滑收合/展開
全覽行程的每一天、記帳的圖表卡片，從原本「瞬間出現/消失」改成平滑的高度展開動畫（約 0.3 秒），視覺上更順暢自然。

### 進場動畫
卡片、清單項目（行程點、花費紀錄、航班住宿卡片等）出現時會有淡入＋輕微上浮的動畫，而且是依序一個接一個出現（有微妙的時間差），不會整批死板地一次跳出來。

### 數字跳動
記帳的總支出金額，只要有變動（新增/刪除/編輯花費），數字會用動畫在 0.45 秒內平滑跳到新數字，而不是瞬間變化——這個效果只有實際操作、眼睛看著畫面時才感受得到，純文字很難描述，建議部署後實際試試看新增一筆花費。

### 圖表與進度條
- 預算進度條（記帳頁、首頁卡片）從 0 平滑長到目標寬度
- 圓餅圖、準備清單的圓環進度、記帳浮動按鈕，出現時有輕微的彈出動畫
- 行程點打勾「已完成」時，背景色轉換跟刪除線都有平滑過渡，不是生硬地瞬間切換

全部改動都經過完整回歸測試，確認跟之前所有功能（刪除復原、打勾完成、搜尋、圖表、多幣別等）相容，沒有任何功能被動畫改動影響到。

## 部署步驟（GitHub Desktop + Vercel）

1. 用 GitHub Desktop 打開你的 repo
2. 把 app.js、style.css、sw.js 覆蓋貼進去
3. Commit to main → Push origin
4. Vercel 自動重新部署

## 之後如果還想再精簡

目前我自己盤點下來，比較大塊的畫面（出發前、記帳、行程）都已經精簡過好幾輪了。如果你實際用起來還是覺得哪個畫面太擠、太多步驟，直接跟我說是哪個畫面、哪個操作卡卡的，我可以針對那個點繼續處理，會比我自己憑空猜測更準確有效率。
