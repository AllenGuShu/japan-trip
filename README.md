# 旅遊紀錄手冊

這次是一次大改版，涵蓋視覺風格、手機版修正、多項功能自動化。

## 這次改了什麼

### 1. 手機版跑版修正
加了一系列防護：長文字自動換行、輸入框不會超出螢幕、全域鎖定水平捲動。之前會跑出畫面的地方（長地名、長交通資訊等）現在都會自動換行收在畫面內。

### 2. 改成日式風格
- 配色從綠色系改成「藍染靛藍 × 朱色 × 生成り紙米白」
- 標題字體改用 Shippori Mincho（日系明朝體），更有日式質感
- App 圖示也重新設計成新配色

### 3. 移除夜間模式
之前的深色模式功能已完全移除（按鈕、程式碼、樣式都拿掉了），現在只有一套配色。

### 4. 修好 Google 地圖金鑰抓不到的 bug
找到真正原因：**如果第一次載入失敗，程式會把「失敗」這個結果永久快取住，導致之後永遠不會重試**，就算金鑰其實是對的也一樣。這次修好了，失敗後下次會自動重新嘗試。另外也加了金鑰驗證失敗時的專屬提示訊息（例如網域限制設定不符時會告訴你）。

### 5. 交通資訊依類型調整欄位
選「租車」會顯示「取車地點／取車時間／還車地點／還車時間」；選「計程車/叫車」會顯示「上車地點／下車地點」，不會再出現不相關的「班次」欄位；選火車/新幹線/公車等維持原本「出發地/抵達地/時間」的欄位。

### 6. 出發前準備清單大幅擴充
從原本 5 類擴充到 8-9 類（證件文件、3C用品、藥品健康、盥洗清潔、衣物穿搭、金錢支付、行李收納、出發前確認、自駕用品），內容豐富很多，一樣可以自由刪除不需要的項目。

### 7. 一鍵開路線圖 + 自動計算車程
單日編輯畫面（有 2 個以上行程點時）新增兩個按鈕：
- **🗺️ 開啟今日路線圖**：一鍵開啟 Google 地圖，顯示當天所有景點依序連成的路線
- **🧭 自動計算車程**：呼叫 Google 地圖的路線規劃服務，自動幫每一站填入「與前一站的車程」，不用再自己估算或手動輸入

（這兩個功能都需要地圖搜尋時選過的真實地標效果最好，直接手打地名系統也會嘗試查詢，但準確度較低）

### 8. 天氣改成自動抓取
拿掉了原本要手動在設定裡填城市名稱的方式。現在只要新增行程點時有用 Google 地圖搜尋選過地標（會記錄座標），系統就會自動抓那個地點當天的天氣，顯示在「整合總覽」的每日標題旁邊，完全不用另外設定。

## 部署步驟（GitHub Desktop + Vercel）

1. 用 GitHub Desktop 打開你的 repo
2. 把這次全部檔案覆蓋貼進去（app.js、index.html、style.css、sw.js、manifest.json、icons 資料夾都有更新）
3. Commit to main → Push origin
4. Vercel 自動重新部署

## 加到手機主畫面（這次建議重新加一次）

因為圖示配色跟 App 名稱顯示都有更新，建議：
1. 先刪除手機上舊的主畫面圖示
2. 部署完成後重新打開網址
3. 依提示重新加入主畫面，這樣新圖示才會生效
