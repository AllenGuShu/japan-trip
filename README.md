# 旅遊紀錄手冊

純前端 PWA，資料存在瀏覽器 localStorage，不需要後端、不需要資料庫。

## 這次修正了什麼

1. **新增旅遊時「出發日期」＋「天數」擠在同一排的問題**：日期選擇器在手機上是系統原生樣式、文字偏大，跟旁邊的天數欄位擠在一起會很難看。已改成兩個欄位各自獨立一整排。住宿表單的「入住日期／退房日期」也是同樣問題，一起修正。
2. **頁首標題疊到手機狀態列（時間/訊號那排）的問題**：把頁首的安全距離抓了一個保底最小值，不會再因為某些情況算出過小的間距而貼到狀態列上。

## 如果狀態列重疊的問題還有出現

這種疊到狀態列的狀況，比較常發生在**用瀏覽器分頁開網址、還沒加到主畫面**的情況下（Safari 網址列會隨滑動收合展開，收合瞬間有時候會跟系統計算的安全距離對不上）。如果你是這種情況，麻煩幫我確認一下：**加到主畫面、用 App 圖示打開之後，這個問題還會不會發生？** 如果加到主畫面後就正常了，那就是瀏覽器分頁的暫時性小狀況，不用太擔心；如果加到主畫面後還是會疊到，麻煩再截圖給我，我繼續往下抓。

## 部署步驟（GitHub Desktop + Vercel）

1. 用 GitHub Desktop 打開你原本的 repo
2. 把 style.css 和 app.js 覆蓋貼進去
3. Commit to main → Push origin
4. Vercel 會自動偵測並重新部署

## 加到手機主畫面

已經加過主畫面圖示的話直接開啟即可。如果畫面看起來還是舊版，把 App 完全關閉（滑掉）再重新打開一次。
