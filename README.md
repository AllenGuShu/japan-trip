# 旅遊紀錄手冊

## 這次新增：分享連結，朋友點開就自動加入

之前要跟朋友一起共編，朋友要自己到首頁「加入共編旅遊」手動輸入代碼。這次加了更快的方式：

- 旅遊 ⚙️設定 →「共同編輯」新增「🔗 分享連結給朋友」按鈕
- 點下去：
  - **手機上**會直接跳出系統分享選單（可以直接傳到 LINE、訊息等）
  - **電腦上**會自動複製連結到剪貼簿
- 朋友收到連結後，不管有沒有開過這個網站，**點開連結就會自動加入這趟旅遊**，完全不用輸入任何代碼
- 原本「複製代碼」「手動輸入代碼加入」的方式也保留著，當備用方案

## 部署步驟（GitHub Desktop + Vercel）

1. 用 GitHub Desktop 打開你的 repo
2. 把這次的 app.js、sw.js 覆蓋貼進去
3. Commit to main → Push origin
4. Vercel 自動重新部署

## 測試方式

進任一趟已經開啟共編的旅遊 → ⚙️設定 →「🔗 分享連結給朋友」，把連結傳給自己的另一台裝置或無痕視窗打開，應該會直接跳進那趟旅遊，不用輸入代碼。
