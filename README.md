# 旅遊紀錄手冊

## 這次優化：記帳畫面精簡美化

### 1. 浮動「＋」按鈕，不用再滑到最下面
右下角新增一個固定的圓形「＋」按鈕，不管畫面滑到哪都能直接點來記一筆，不用再滑到清單最底部。

### 2. 總覽卡片整合
原本「總支出」跟「預算」是兩張獨立卡片，現在合併成一張：金額大字顯示在最上面，底下直接接預算進度條（有設定才會顯示，沒設定就不佔版面）。匯率也從一個大按鈕改成小圖示（🔄），畫面更乾淨但功能都還在。

### 3. 分帳結算移到清單下方、合併成一張卡片
「分帳成員」跟「分帳結算」原本是兩張卡片，現在合併成一張「👥 分帳」卡片，並且移到花費清單下方——因為多數時候你在意的是「花了多少、要記一筆」，分帳結算通常是旅程結束前才會特別去看，放後面比較符合使用順序。

整體畫面順序變成：**總覽（含預算）→ 分類小計 → 花費清單 → 分帳結算 → 浮動新增按鈕**，重點資訊都還在，只是更緊湊、閱讀動線更順。

已經測試過：浮動按鈕能正常開啟新增表單、總覽卡片正確顯示金額與預算、分帳結算合併卡片運作正常、即時匯率抓取正常。

## 記帳還可以加什麼？（建議，還沒做）

1. **圖表視覺化** — 圓餅圖顯示各類別花費佔比，比文字更直覺
2. **每日花費小計** — 在「行程」的整合總覽裡，每天標題旁順便顯示當天花了多少
3. **快速常用項目** — 記錄幾個常按的項目（例如「超商」「計程車」），一鍵帶入類別不用每次選
4. **超支即時提醒** — 新增花費當下如果超過該類別預算，跳出提示（現在要自己回記帳頁看才會發現）
5. **匯出記帳明細** — 存成 Excel/CSV，方便旅遊結束後整理報帳或留存
6. **多幣別花費** — 目前一趟旅遊只能用單一貨幣記帳，如果同一趟會經過多國、或當地same時用到不同幣別，可以讓單筆花費自己選幣別
7. **收據照片** — 拍照存證，不過這個需要額外的圖片儲存空間，目前的架構（純文字資料庫）還沒支援
