# 旅遊紀錄手冊

## 這次優化：圖表視覺化 + 精簡

### 1. 記帳圖表（圓餅圖 + 長條圖）
記帳頁分類小計上方新增一張「📊 花費圖表」卡片，**預設收合**（不佔版面，符合精簡原則），點開才展開：
- **分類佔比圓餅圖**：一眼看出錢花在哪（交通/住宿/餐飲/門票/購物/其他，各類別有專屬顏色），旁邊附文字圖例（金額＋百分比）
- **每日花費長條圖**：只要花費有填日期，就會自動統計每天花多少，一眼看出哪天花最多（沒填日期的花費不會計入這個圖表）

### 2. 準備清單圓環進度
「準備進度」從純文字「X/Y」改成一個小圓環進度條，視覺上更清楚完成度，圓環中間仍保留 X/Y 數字。

### 3. 首頁旅遊卡片更視覺化
每張旅遊卡片新增：
- **倒數天數徽章**：「X 天後出發」，3 天內會變成醒目的提醒色，過去的旅遊顯示「旅途愉快 🎌」
- **預算迷你進度條**：如果有設定總預算，卡片上直接顯示一條小進度條＋花費/預算數字，不用點進去才看得到，接近或超支會變色提醒

### 4. 出發前畫面精簡
- 四個子分頁（航班/住宿/交通/準備）標籤旁邊直接顯示**數量徽章**（例如「✈️ 航班 2」「🧳 準備 12/56」），不用點進去才知道有幾筆
- 每張卡片（航班/住宿/交通）的內距跟行距都收緊了一些，資訊量沒變但看起來更緊湊

全部功能都測試過：圖表收合展開正常、圓餅圖與長條圖資料正確、圓環進度顯示正確、首頁倒數與預算計算正確、子分頁數量徽章正確顯示。

## 部署步驟（GitHub Desktop + Vercel）

1. 用 GitHub Desktop 打開你的 repo
2. 把 index.html、app.js、style.css、sw.js 覆蓋貼進去
3. Commit to main → Push origin
4. Vercel 自動重新部署
