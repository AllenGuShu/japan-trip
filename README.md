# 旅遊紀錄手冊

## 這次優化三項

### 1. 全覽行程精簡化（可收合）
「行程」分頁的「整合總覽」現在每一天都變成**可收合的項目**，預設全部收合，只看到每天的標題（日期、天氣、幾個景點）一行，點下去才展開看細節。上方新增「展開全部／收合全部」按鈕方便切換。景點清單也改成更緊湊的條列式，不再是一張一張大卡片。天數多的旅遊應該會清爽很多。

### 2. 記帳匯出 Excel/CSV
記帳頁分類小計那排旁邊新增「📤」匯出按鈕，會產生一份 CSV 檔（Excel 可以直接開，中文編碼已處理好不會亂碼），內容包含：日期、類別、項目、幣別、金額、換算 TWD、付款人、分攤對象、備註，最後還有總計列。

順便幫每筆花費加了「日期」欄位（選填，新增時預設今天），這樣匯出的明細才能照日期排序查看。

### 3. 多幣別花費
新增花費時多了「貨幣」選項，預設「與旅遊相同」，也可以選其他國家貨幣或自訂幣別（例如跨國旅遊時在別的國家刷卡消費）。選了之後會自動帶入該幣別的參考匯率，也可以手動調整。

**這是比較複雜的部分，這裡說明一下計算邏輯**：因為不同貨幣不能直接加總，所以「總支出」「預算進度」「分帳結算」現在都是先把每一筆換算成台幣（用該筆自己的匯率）加總，再換算回旅遊主要貨幣顯示金額——確保就算你有幾筆用不同貨幣記的花費，總數字還是準確的，分帳結算也會公平考慮到匯率差異。用了超過一種貨幣時，總覽那邊會提示「使用了 N 種貨幣」；每一筆花費如果不是旅遊主要貨幣，項目旁邊會有小標籤標示幣別。

三項都用實際數字測試過（例如日圓+美金混合記帳，驗證台幣總額計算完全正確）。

## 部署步驟（GitHub Desktop + Vercel）

1. 用 GitHub Desktop 打開你的 repo
2. 把 index.html、app.js、style.css、sw.js 覆蓋貼進去
3. Commit to main → Push origin
4. Vercel 自動重新部署
