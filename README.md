# 旅遊紀錄手冊

純前端 PWA，資料預設存在瀏覽器 localStorage；設定好 Firebase 後可選擇性開啟「共同編輯」雲端同步。

## 這次新增：Google 地圖搜尋內建到網站

之前 Google 地圖搜尋功能需要每個人自己在 🔑 設定裡貼一次金鑰才能用。這次改成**金鑰直接內建在網站程式碼裡**：

- 任何人打開你的網站，不用做任何設定，新增行程點/住宿時就能直接搜尋 Google 地圖真實地標
- 因為這組金鑰已經限制成只能在你的網域上使用，內建在程式碼裡是安全的
- 如果朋友想用自己的金鑰（例如你不想大家都算在你的額度裡），還是可以到 🔑 設定裡貼自己的金鑰覆蓋，清除後會自動恢復用內建的那組

## 金鑰放在哪裡

新增了一個檔案 `maps-config.js`，內建金鑰就寫在裡面。之後如果要換金鑰（例如額度用量考量、金鑰不小心外流要重新產生），直接編輯這個檔案換掉字串即可，不用改 app.js。

## 部署步驟（GitHub Desktop + Vercel）

1. 用 GitHub Desktop 打開你原本的 repo
2. 把這次全部檔案（含新的 `maps-config.js`）覆蓋貼進去
3. Commit to main → Push origin
4. Vercel 會自動偵測並重新部署

## 加到手機主畫面

已經加過主畫面圖示的話直接開啟即可。如果畫面看起來還是舊版，把 App 完全關閉（滑掉）再重新打開一次。

## 之前功能提醒

- **🔄 共同編輯**：需要申請 Firebase 才能用，還沒設定的話會顯示「尚未設定」，其他功能不受影響
- **分帳結算**：記帳頁可以新增旅伴、標記誰付款/算誰的份，自動算出最少轉帳次數的結算建議
