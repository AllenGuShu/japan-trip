# 旅遊紀錄手冊

純前端 PWA，資料存在瀏覽器 localStorage，不需要後端、不需要資料庫。

## 這次大改版了什麼

### 底部導覽簡化成 4 個分頁
🧳 出發前 → 🛣️ 行程 → 💰 記帳 → 💬 會話
字變大了、不再擠成一團。

### 移除／合併
- **提醒（注意事項）分頁移除**，不再顯示於底部導覽
- **景點分頁移除**，改成直接在「行程」的「新增行程點」裡就能選標籤（美食/購物/自然/文化/歷史/夜景/親子/秘境/打卡），不用再切去另一頁重打一次地名
- **準備清單併入「出發前」**，變成第 4 個子頁籤（✈️航班 / 🏨住宿 / 🚌交通 / 🧳準備）

### 日期自動化
- 新增旅遊時多了「出發日期」欄位（選填），填了之後 Day 1～N 的日期會自動排好，不用再進到每一天手動選
- 單日編輯裡的日期改成**唯讀顯示**（例如「8/21（週五）」），不能誤觸修改，真的要調整的話到 ⚙️ 設定重新設定出發日期、按「套用日期到每一天」即可
- ⚙️ 設定新增一天時，日期會自動接續前一天

### 修掉的問題
- 單日行程編輯那排「Day 1」+ 日期欄位跑版跑出螢幕外的問題已修正（原因是日期輸入框在小螢幕上無法正確縮小，現在改成唯讀徽章就不會有這個問題了）
- 單日編輯移除了「這天的心得/遊記」輸入欄位，畫面更單純，只留新增行程點

### 常用例句擴充
日文／英文的每個場景（加油站、餐廳、問路等）從原本 2-3 句擴充到 **8 句**。

## 部署步驟（GitHub Desktop + Vercel）

1. 用 GitHub Desktop 打開你原本的 repo
2. 把這次全部檔案（index.html、style.css、app.js、manifest.json、sw.js）覆蓋貼進去
3. Summary 填「簡化導覽、景點併入行程、自動日期、擴充例句」→ Commit to main → Push origin
4. Vercel 會自動偵測並重新部署

## 舊資料會怎樣

之前用「景點」分頁加的地點，因為那個分頁移除了，暫時不會顯示在畫面上（資料還在檔案裡，沒有被刪除，只是沒有入口可以看）。如果你有重要的舊景點資料想找回來，可以匯出旅遊檔案傳給我，我可以幫你寫個小工具把它們轉進行程裡。之前設定過的「注意事項」提醒同理，資料還在但沒有畫面可看。

## 加到手機主畫面

已經加過主畫面圖示的話直接開啟即可。如果畫面看起來還是舊版，把 App 完全關閉（滑掉）再重新打開一次。
