# 旅遊紀錄手冊

純前端 PWA，資料存在瀏覽器 localStorage，不需要後端、不需要資料庫。

## 這次更新了什麼

- 首頁一開始**完全沒有旅遊**，一定要手動點「＋ 新增一趟旅遊」才會建立
- 新增旅遊時多了：**國家/地區選擇**（20 個常見國家 + 自訂）、**交通方式**（自駕／大眾運輸／都有）
- 選了國家會自動帶入對應貨幣，記帳頁會用當地貨幣符號顯示（¥ / $ / € / ₩ ... 等）
- 記帳頁新增「📡 抓即時匯率」按鈕，會即時查詢當地貨幣兌台幣匯率並自動填入（需要網路連線）
- 行前準備清單、注意事項會依「是否自駕」「是否為日本」條件式產生（例如非自駕就不會出現國際駕照）
- 會話小抄：選日本會給日文例句，其他國家給通用英文例句，都可以自己加自訂例句
- ⚙️ 設定頁可以事後修改國家/貨幣/交通方式、新增天數
- 如果你手機上還留著舊版資料（不管是單一趟還是舊版多趟），第一次打開新版時會自動搬進來，不會遺失

## 部署步驟（GitHub Desktop + Vercel）

1. 用 GitHub Desktop 打開你原本的 repo（同一個，不用建新的）
2. 把這次的檔案（index.html、style.css、app.js、manifest.json、sw.js）覆蓋貼進資料夾
3. Summary 填「支援多國家與貨幣」→ Commit to main → Push origin
4. Vercel 會自動偵測並重新部署

## 加到手機主畫面

已經加過主畫面圖示的話**不用重新加**，直接開啟即可。如果畫面看起來還是舊版，把 App 完全關閉（滑掉）再重新打開一次。

## 匯率查詢說明

即時匯率使用免費公開 API（open.er-api.com），資料每日更新一次，適合抓「大概匯率」使用；若需要精確兌換金額，建議以實際兌換或刷卡當下的匯率為準。若該貨幣是自訂輸入（例如很少見的幣別），系統可能查不到，此時請手動輸入匯率。

## 資料保存

所有資料都存在**該台裝置瀏覽器**的 localStorage，換裝置或清瀏覽器資料會遺失，目前沒有雲端同步機制。
