# 旅遊紀錄手冊

純前端 PWA，資料存在瀏覽器 localStorage，不需要後端、不需要資料庫。

## 這次讓它更像 App 了

- **安裝提示橫幅**：如果你是用瀏覽器開網址、還沒加到主畫面，畫面下方會自動跳出提示
  - Android/Chrome：會有「安裝」按鈕，點了直接跳出系統安裝視窗
  - iOS/Safari：因為蘋果不開放自動安裝，會顯示「點下方分享按鈕 → 加入主畫面」的操作提示
  - 已經加到主畫面、用 App 圖示打開時完全不會顯示這個橫幅
  - 點右邊 ✕ 關閉後就不會再跳出來
- **更完整的圖示**：補齊了 iOS（180/152/167）、favicon（32）等各種尺寸，加到主畫面後圖示會更清晰
- **App 捷徑**：在 Android 長按主畫面圖示，會出現「新增一趟旅遊」的快速捷徑，直接跳出新增表單
- **滑動手感更像原生 App**：拿掉了下拉整頁彈跳、點擊時的藍色閃爍高亮，按鈕的點擊回饋更即時

## 部署步驟（GitHub Desktop + Vercel）

1. 用 GitHub Desktop 打開你原本的 repo
2. 把這次全部檔案（index.html、style.css、app.js、manifest.json、sw.js、icons 資料夾）覆蓋貼進去
3. Summary 填「加強 App 體驗：安裝提示、圖示、捷徑」→ Commit to main → Push origin
4. Vercel 會自動偵測並重新部署

## 加到手機主畫面（更新後建議重新加一次）

因為這次新增了圖示尺寸跟捷徑功能，建議：
1. 先把手機上舊的主畫面圖示刪除
2. 開瀏覽器連到網址，這次應該會自動跳出安裝提示
3. 依提示加入主畫面，新圖示跟捷徑就會生效

## 之後如果想上架到 App Store / Google Play

目前這樣「加到主畫面」用起來已經很接近原生 App。如果之後真的想上架讓別人也能在商店搜尋下載，可以用 PWABuilder（免費，拿現有網址就能產生安裝包）或 Capacitor（把網頁包成原生專案，客製化空間更大），兩者都需要對應的開發者帳號與 Mac/Xcode（iOS）。想做的話再跟我說，我可以帶你一步步弄。

## 資料保存

所有資料都存在**該台裝置瀏覽器**的 localStorage，換裝置或清瀏覽器資料會遺失。可以用「匯出成檔案」備份，到另一台裝置「匯入」還原。
