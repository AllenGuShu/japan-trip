# 旅遊紀錄手冊

## 這次新增：全部項目都可以編輯了

延續上次行程點的編輯功能，這次把「出發前」跟「記帳」裡的所有項目都加上「✏️ 編輯」按鈕：

- ✈️ **航班** — 點編輯會帶入原本的航空公司、班號、時間等資料，改完存檔原地更新
- 🏨 **住宿** — 同上，包含地址、入住退房日期
- 🚌 **交通** — 這個比較特別，因為租車/計程車/火車等類型欄位不一樣，編輯時會**自動根據原本的類型顯示對應欄位**並正確帶入資料，切換類型也會保留你已經填的內容
- 💰 **記帳** — 金額、類別、付款人、分攤對象都能重新調整
- 🧳 **準備清單項目** — 每個項目旁邊加了小編輯按鈕，可以直接改文字內容，不用刪除重打

全部都測試過：編輯後資料是原地更新（不會變成重複兩筆），各欄位（包含比較複雜的交通類型切換）都正確預填跟儲存。

## 部署步驟（GitHub Desktop + Vercel）

1. 用 GitHub Desktop 打開你的 repo
2. 把 app.js、sw.js 覆蓋貼進去
3. Commit to main → Push origin
4. Vercel 自動重新部署
