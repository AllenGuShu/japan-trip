# 旅遊紀錄手冊

純前端 PWA，資料存在瀏覽器 localStorage，不需要後端、不需要資料庫。

## 這次修正深色模式的顏色問題

找到真正的原因了，主要有兩個：

1. **右上角金色「0 趟旅程」徽章**：文字顏色原本用會隨深色模式變亮的綠色，導致金色底配螢光綠字，非常刺眼。已改成固定深綠色，不管淺色/深色模式都跟原本一樣好看。
2. **自訂貨幣輸入框沒有套用深色樣式**：選「其他（自訂）」國家時出現的「貨幣代碼」「貨幣符號」兩個輸入框，還有分類預算的小輸入框，這些欄位深色模式下完全沒套用主題顏色，會變成刺眼的純白色方塊浮在暗色畫面上。已修正，統一套用深色主題。
3. 順手把提示文字（field hint）預設改回中性灰色，不再整個畫面到處都是綠色字，只有真正成功的提示（例如「✓ 已鎖定地標」）才維持綠色。

## 部署步驟（GitHub Desktop + Vercel）

1. 用 GitHub Desktop 打開你原本的 repo
2. 這次只有 style.css 和 app.js 有變動（app.js 只改了兩行成功提示的樣式），全部檔案覆蓋貼進去最保險
3. Commit to main → Push origin
4. Vercel 會自動偵測並重新部署

## 加到手機主畫面

已經加過主畫面圖示的話直接開啟即可。如果畫面看起來還是舊版，把 App 完全關閉（滑掉）再重新打開一次。
