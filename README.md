# 旅遊紀錄手冊

## 這次優化三項

### 1. 刪除加保護（可復原）
之前所有刪除按鈕都是點了就直接消失，很容易誤觸。現在刪除行程點、航班、住宿、交通資訊、記帳、準備清單項目、自訂例句時，畫面下方會跳出「已刪除「XXX」　[復原]」的提示條，**5 秒內**點「復原」就能救回來，超過時間提示會自動消失（但資料還是真的刪掉了，不會佔用空間）。成員刪除因為會牽動花費裡的付款/分攤紀錄，改成用確認對話框保護，避免複雜的還原邏輯出錯。

### 2. 行程點可打勾「已完成」
單日編輯跟整合總覽的每個行程點旁邊都新增「已完成」打勾選項，適合旅途中或結束後回來標記實際去過哪裡。打勾後：
- 名稱會加上刪除線、卡片變成淡綠色背景
- 整合總覽的每天標題會顯示「🛣️ 3/5 站」這種完成進度
- 搜尋結果裡也會顯示完成狀態

### 3. 行程搜尋
「行程」分頁上方新增搜尋框，輸入關鍵字（景點名稱、標籤都可以搜）會列出所有符合的行程點，顯示在哪一天、幾點、什麼標籤，點一下就直接跳到那一天的單日編輯畫面。天數多、行程點多的旅遊終於不用一天一天翻找了。

三項都完整測試過（包含比較細節的情境，例如復原後完成狀態也會一併還原、整合總覽打勾後標題即時更新、搜尋清空後正確恢復正常畫面）。

## 部署步驟（GitHub Desktop + Vercel）

1. 用 GitHub Desktop 打開你的 repo
2. 把 index.html、app.js、style.css、sw.js 覆蓋貼進去
3. Commit to main → Push origin
4. Vercel 自動重新部署
