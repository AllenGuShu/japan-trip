# 旅遊紀錄手冊

## 這次改的：同步失敗時終於看得到原因了

之前同步失敗（例如網路問題、Firebase 設定有誤）都是在背景默默失敗，畫面上完全看不出來，這也是你這次遇到「改了但沒同步」卻不知道為什麼的主因。

### 新增內容
旅遊 ⚙️設定 →「共同編輯」區塊，現在多了：
- **即時同步狀態列**：顯示「🔄 同步中」「✓ 已同步（時間）」或「⚠️ 錯誤原因」，錯誤時會直接告訴你具體原因（例如「權限被拒絕」會提示去檢查 Firestore 安全規則）
- **🔄 立即重新連線並同步一次**按鈕：可以手動強制重新連線＋推送一次，不用等自動觸發

## 🔍 麻煩幫我排查一下：請照這幾步做

1. 部署完這次更新後，打開你**手機**上的旅遊手冊，進那趟共編中的旅遊 → ⚙️設定
2. 看「共同編輯」區塊的狀態列，截圖給我
3. 點「🔄 立即重新連線並同步一次」，再截圖一次狀態列變成什麼
4. 電腦那邊同樣操作一次，也截圖給我

這樣我就能直接看到錯誤代碼，精準判斷是規則沒發布、網路問題、還是別的原因，不用再用猜的。

## 我猜最可能的原因（可以先自己檢查）

Firestore 安全規則很可能沒有真正發布成功。麻煩檢查：
1. 打開 Firebase 後台 → 你的 `trip-journal` 專案 → Firestore Database → 上方「**規則**」分頁
2. 確認內容是：
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /trips/{tripCode} {
         allow read, write: if true;
       }
     }
   }
   ```
3. 畫面上如果有「發布」按鈕還亮著沒按過，記得要按
4. 如果距離上次發布已經超過 30 天，測試模式規則可能已經自動失效，需要重新發布一次
